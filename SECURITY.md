# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do **NOT** open a public GitHub issue. 

Please follow these steps:
1. Email details directly to **nizarsaidi.dev@gmail.com**.
2. Include steps to reproduce, affected components, and potential impact.
3. Allow up to 48 hours for an initial response before public disclosure.
